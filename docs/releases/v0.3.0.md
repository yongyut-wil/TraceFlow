# TraceFlow v0.3.0 — Polish & Refinement

**Date:** 2025-10-22 · **Baseline:** `98bf619` on `master` · **Closes:** ISSUE-008, ISSUE-009, ISSUE-010

![TraceFlow live demo](../assets/live-demo.gif)

A polish release driven by a measured responsive audit (13 viewports,
2560→320px) and a full design-system token review. No breaking changes.

## ✨ Highlights

- **Signal-linked visuals** — KPI cards now carry a left border in their
  metric's signal color (emerald live / violet mean / cyan peak / amber
  anomalies), and every panel header has a 2px accent tick identifying its
  data class at a glance.
- **Traces got a body** — both charts render gradient area fills
  (cyan `16%→0`, violet `18%→0`) under the polyline instead of bare neon
  strokes; grid lines softened to `rgba(30,41,59,.55)`.
- **Border hierarchy** — new `--edge` tier (`#334155`) separates
  *interactive* controls from *structural* hairlines; selects, inputs, the
  range rail, and pause now read as pressable.
- **Responsive floor verified** — `overflowX = 0` measured on all 13
  viewports including 320×568; the anomaly table now fits 360px+ without
  horizontal scrolling.

## 🐛 Fixes

| Item | Before | After |
|---|---|---|
| Compare select | `throughput_ry` truncated ≤1440px | full label (`w-40`) |
| markLine labels | clipped at right edge ≤390px | `insideStartTop`, fully visible |
| Anomaly table | 417px min-width → h-scroll on phones | `px-2 sm:px-3`, fits 360px+ |
| ZoomIn action | 20px touch target | 24px (WCAG 2.5.8) |
| SEV badge | `text-[8px]` below spec floor | `text-[9px]` |
| label-caps | `tracking-wider` (0.05em) | `0.08em` per spec |
| KPI gutter | 12px on mobile | 8px per spacing spec |

## 🎨 Design tokens

- New: `--live` / `--warn` / `--crit` signal tokens, `--raised` surface
  (`#101B2C`), `--edge` border (`#334155`)
- `text-dim` (`#475569`) now actually used — `--` placeholders and the
  anomaly empty state take the muted tier
- All emerald/amber/rose Tailwind literals replaced by tokens — single
  source of truth, no drift risk
- Icons: `Zap` (current), `Sigma` (window mean), `TrendingUp` (peak),
  `WifiOff` (disconnected)
